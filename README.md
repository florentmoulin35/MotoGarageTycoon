# Moto Garage Tycoon

Jeu de gestion d'une concession moto multimarque, avec boutique d'accessoires et atelier, en cartoon 3D (three.js).

- Choisis ta marque de départ parmi 9 constructeurs, puis signe des accords avec les autres.
- Plus de 70 motos réparties en 125, A2 et A, avec 4 designs : roadster, trail, sportive, routière.
- Prix libres, accessoires (casques, gants, blousons, bottes), atelier (révision, pneus, réparation).
- Progression par niveaux, objectifs du jour, améliorations du magasin.
- Le temps n'avance que quand tu joues. La partie est sauvegardée dans le navigateur.

Pour jouer : ouvre `index.html` dans un navigateur, ou active GitHub Pages sur la branche `main`.
