# Moto Garage Tycoon

Jeu de gestion d'une concession moto multimarque, avec boutique d'accessoires et atelier de réparation, en cartoon 3D (three.js).

- Choisis ta marque de départ (Honda, Yamaha, Suzuki, Ducati, CFMoto), puis signe des accords avec d'autres constructeurs.
- Le temps n'avance que quand tu joues. La partie est sauvegardée dans le navigateur.

Pour jouer : ouvre `index.html` dans un navigateur, ou active GitHub Pages sur la branche `main`.
